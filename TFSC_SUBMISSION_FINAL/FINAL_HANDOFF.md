## Core contribution (3 sentences)

Technological progress can change which authentication institution is
rational — not merely how secure a fixed one remains. We model
endogenous regime transitions among fixed, rotating, lineage-preserving,
and exit regimes under a technology state covering assay, synthesis,
microfabrication, and verification costs, calibrated on measured
meteorite fingerprints. All physical-provenance regimes possess a
quantifiable technological expiration frontier.

## Negative findings (reported, not hidden)

- Bulk predecessor-metal chaining adds zero security under synthetic attack (M3a ≡ M2).
- Adaptation is dominated by earlier exit under attacker-favoring progress.
- No hysteresis and no path dependence — all transitions viability-forced.
- Rule C (backward dynamic programming, β=0.9) reproduces Rule A exactly.
